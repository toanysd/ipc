Lưu ý về UPnP & máy tắt
✅ UPnP TTL đã tăng lên 86400 giây (24h). Rule trên router sẽ tồn tại tối đa 24h kể từ lần renew cuối cùng — tức là nếu laptop tắt dưới 24h, camera vẫn có thể truy cập từ ngoài.
⚠️ Để camera luôn truy cập được dù laptop tắt lâu hơn, hãy cấu hình Port Forward tĩnh trên router. Xem hướng dẫn ở tab Router tĩnh.

Cấu hình Port Forward tĩnh trên Router
Tại sao cần cấu hình tĩnh?

UPnP tự động mở cổng nhưng có TTL giới hạn — rule sẽ bị xóa nếu laptop tắt lâu hơn 24h. Khi cấu hình Port Forward tĩnh trực tiếp trên router, rule tồn tại vĩnh viễn dù laptop hay camera client tắt.

⚠️ Nếu ISP cấp IP động (thay đổi), hãy dùng DDNS (DuckDNS, No-IP…) để có domain cố định thay vì IP.

💡 Cổng 10554+ trỏ thẳng vào IP camera (không qua laptop) — camera vẫn xem được dù laptop tắt.

Hướng dẫn theo hãng router
  1. Mở trình duyệt, vào http://192.168.0.1 (hoặc http://tplinkwifi.net). Đăng nhập bằng tài khoản admin router.
  2. Vào menu Advanced → NAT Forwarding → Virtual Servers.
  3. Bấm Add. Điền thông tin:
    • External Port: 1984
    • Internal IP: IP laptop (ví dụ 192.168.1.100)
    • Internal Port: 1984
    • Protocol: TCP
    Bấm Save. Lặp lại cho các cổng còn lại.
  4. Để forward thẳng vào camera (không cần laptop), đặt Internal IP là IP camera (ví dụ 192.168.1.200) và Internal Port là 554.
  5. Bấm Save và Reboot router nếu được yêu cầu.
  1. Vào http://192.168.1.1 hoặc http://router.asus.com. Đăng nhập.
  2. Vào WAN → Virtual Server / Port Forwarding.
  3. Bấm Add profile. Điền:
    • Service Name: ServiceManager-API
    • Protocol: TCP
    • External Port: 1984
    • Internal IP: IP laptop hoặc IP camera
    • Internal Port: 1984 (hoặc 554 cho camera trực tiếp)
  4. Bật công tắc Enable Virtual Server ở đầu trang nếu chưa bật.
  5. Bấm Apply.
  1. Vào http://192.168.0.1. Đăng nhập (mặc định: admin / không mật khẩu).
  2. Vào Advanced → Port Forwarding.
  3. Bấm Add Rules. Điền:
    • Name: SvcMgr-API
    • IP Address: IP laptop hoặc IP camera
    • TCP: 1984
    Lặp lại cho cổng 8555, 10554.
  4. Bấm Save Settings.
MikroTik dùng lệnh terminal hoặc Winbox. Dưới đây là lệnh RouterOS.

Mở Winbox → IP → Firewall → NAT → Add (+):

  1. Tab General: Chain = dstnat, Protocol = tcp, Dst. Port = 1984.
  2. Tab Action: Action = dst-nat, To Addresses = IP laptop, To Ports = 1984. Bấm OK.
  3. Hoặc dùng lệnh terminal:
    /ip firewall nat add chain=dstnat protocol=tcp dst-port=1984 action=dst-nat to-addresses=192.168.1.100 to-ports=1984
  4. Lặp lại cho cổng 8555, 10554 (với to-addresses là IP camera cho cổng 10554).
⚠️ Modem VNPT/Viettel thường có 2 lớp NAT (modem + router). Nếu router cắm vào modem, bạn cần forward cổng trên cả hai thiết bị, hoặc đặt router vào DMZ của modem.
  1. Vào http://192.168.1.1 (modem VNPT) hoặc http://192.168.0.1 (Viettel). Tài khoản thường là admin / admin hoặc in ở nhãn modem.
  2. Tìm mục Port Mapping, Virtual Server, hoặc NAT/DMZ (tuỳ firmware).
  3. Thêm rule:
    • WAN Port: 1984 → LAN IP laptop : 1984
    • WAN Port: 8555 → LAN IP laptop : 8555
    • WAN Port: 10554 → LAN IP camera : 554
  4. Nếu không tìm thấy mục Port Mapping, đặt IP router của bạn vào DMZ của modem để modem chuyển toàn bộ traffic về router, rồi cấu hình port forward trên router.
  5. Lưu & khởi động lại modem.
Kiểm tra sau khi cấu hình
  1. Truy cập canyouseeme.org — nhập từng cổng (1984, 8555, 10554) để kiểm tra từ internet.
  2. Thử URL RTSP camera trực tiếp từ mạng khác: rtsp://<IP_công_cộng>:10554/stream1 bằng VLC.
  3. Nếu ISP đổi IP công cộng thường xuyên, đăng ký DuckDNS (miễn phí) và cài agent cập nhật IP tự động.
